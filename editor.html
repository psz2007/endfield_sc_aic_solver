使用提示

平移工具 (M)：拖动机器或空白处平移；点机器选中；选中后点边缘端口圆点循环切换"空闲端口声明"（无 → 管出 → 带出 → 带入 → 管入）。
传送带 (E) / 管道工具 (Q)：点中一个机器边缘的端口圆点开始连接，再点另一个机器的端口完成；自动确定出/入方向。
右键端口可删除占用它的连接 / 空闲声明；删除连接时，被释放的端口会自动保留为空闲端口声明。
WASD 平移画布（Shift 加速）；R 旋转选中机器（无选中则旋转视图，纯视觉，不改底层数据 / 求解器约束）；Esc 取消连接 / 切回平移工具。
导入 JSON…：会自动识别 .aic.json / solution.json 进入预览，可在顶部切换查看原始设计 / 求解结果，并按需保存到编辑器。
空闲端口（虚线圆边）= 物理上有但未连传送带/管道，会作为求解器候选位置。
